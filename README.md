## 🔬 รายละเอียดเนื้อหาในแต่ละสมุดงาน (Notebook Breakdown)

### 1. Data Analytics & Exploratory Data Analysis (EDA)

#### 🚆 `EDA_Public_Transportation_Final.ipynb`
* **หัวข้อ:** การวิเคราะห์เชิงสำรวจข้อมูลระบบขนส่งสาธารณะ (Public Transportation Analysis)
* **เป้าหมาย:** วิเคราะห์พฤติกรรมการเดินทาง ความหนาแน่นของช่วงเวลาเร่งด่วน (Peak Hours) และการกระจายตัวของสถานี/เส้นทาง
* **กระบวนการหลัก:**
  - Data Cleaning, การจัดการค่าสูญหาย (Missing Values) และการแปลง Time-series / Datetime
  - สถิติเชิงพรรณนา (Descriptive Statistics) และการสร้างภาพข้อมูล (Data Visualization) ด้วย Matplotlib & Seaborn
  - การระบุจุดคอขวด (Bottlenecks) และสรุปข้อเสนอแนะเชิงลึกเพื่อการบริหารจัดการเส้นทางเดินรถ

---

### 2. Machine Learning & Predictive Modeling

#### 💤 `Sleep_Stage_Classification_XGBoost.ipynb`
* **หัวข้อ:** การจำแนกระยะการนอนหลับด้วย XGBoost (Sleep Stage Classification)
* **เป้าหมาย:** ทำนายระยะการนอน (เช่น Wake, N1, N2, N3, REM) จากข้อมูลสัญญาณสรีรวิทยาและฟีเจอร์เชิงสถิติ
* **กระบวนการหลัก:**
  - Data Preprocessing และ Feature Engineering สำหรับข้อมูลสัญญาณแบบช่วงเวลา
  - การจัดการปัญหา Class Imbalance ในระยะการนอน
  - การเทรนและปรับแต่ง Hyperparameters ของแบบจำลอง **XGBoost Classifier**
  - การประเมินผลด้วย Confusion Matrix, Precision, Recall, Macro-F1 Score และ ROC-AUC

---

### 3. Computer Vision & Document AI

#### 🏠 `House_Recognition.ipynb`
* **หัวข้อ:** การรู้จำและจำแนกประเภทบ้าน/สถาปัตยกรรม (House Scene & Architecture Recognition)
* **เป้าหมาย:** สร้างโมเดล Deep Learning เพื่อจำแนกประเภท สไตล์ หรือองค์ประกอบของบ้านจากรูปภาพ
* **กระบวนการหลัก:**
  - Image Preprocessing, Resizing, Data Augmentation เพื่อเพิ่มความทนทานต่อมุมกล้องและแสง
  - การใช้ Convolutional Neural Networks (CNN) / Pretrained Backbones (Transfer Learning)
  - การวัดประสิทธิภาพการจำแนกภาพ (Top-1 Accuracy, Loss Curves)

#### 🔍 `OCR_EasyOCR.ipynb`
* **หัวข้อ:** การสกัดข้อความจากภาพด้วย EasyOCR (Optical Character Recognition)
* **เป้าหมาย:** แปลงตัวอักษรในภาพเอกสารหรือป้ายให้อยู่ในรูปแบบข้อความดิจิทัล รองรับภาษาไทยและภาษาอังกฤษ
* **กระบวนการหลัก:**
  - การเตรียมภาพด้วย OpenCV (Grayscale, Thresholding, Binarization, Noise Removal)
  - การประยุกต์ใช้โมเดล CRAFT (Text Detection) และ ResNet-LSTM-CTC (Text Recognition) ผ่านไลบรารี EasyOCR
  - การกรอง Bounding Boxes และการจัดการผลลัพธ์ข้อความภาษาไทยที่มีสระ/วรรณยุกต์หลายระดับ

---

### 4. Natural Language Processing (NLP)

#### 🇹🇭 `thai_word_segmentation_wangchanberta.ipynb`
* **หัวข้อ:** การตัดคำภาษาไทยด้วย WangchanBERTa (Thai Word Segmentation)
* **เป้าหมาย:** แก้ปัญหาความท้าทายของภาษาไทยที่ไม่มีการเว้นวรรคระหว่างคำ โดยใช้สถาปัตยกรรม Pre-trained Transformer
* **กระบวนการหลัก:**
  - การใช้โมเดล `airesearch/wangchanberta-base-att-spm-uncased` ผ่าน Hugging Face Transformers
  - การแปลงปัญหาการตัดคำเป็นงาน Sequence Labeling / Token Classification (BIO Tagging)
  - การเปรียบเทียบผลลัพธ์กับ Dictionary-based / Maximal Matching Algorithms แบบดั้งเดิม

---

### 5. Large Language Models (LLMs) & RAG Challenge Series

ชุดสมุดงานการแข่งขัน **RAG Challenge 1** สำหรับการสร้างระบบค้นคืนและตอบคำถาม (Question-Answering System) ผ่านเอกสารบริบทภาษาไทย โดยทำการทดสอบและเปรียบเทียบประสิทธิภาพระหว่างโมเดลภาษาขนาดใหญ่ชั้นนำ:

| Notebook | Base Foundation LLM | จุดเด่นและโฟกัสของการทดลอง |
| :--- | :--- | :--- |
| **`OpenThaiGPT_rag_challenge_1_original.ipynb`** | **OpenThaiGPT** | การทดสอบโอเพนซอร์สโมเดลภาษาไทยจากความร่วมมือของภาคี AI ไทย การวัดผลการสร้างคำตอบและการสรุปความ |
| **`Pathumma_fahmai_rag_challenge_1_original.ipynb`** | **Pathumma + Fahmai** | การเชื่อมต่อโมเดล Pathumma บนแพลตฟอร์ม/โครงสร้าง Fahmai เน้นการทดสอบความแม่นยำในการอ้างอิงเอกสาร |
| **`THaLLE_Pathumma_fahmai_rag_challenge_1_original.ipynb`** | **THaLLE + Pathumma (Fahmai)** | การทดสอบ RAG ร่วมกับ THaLLE ซึ่งเน้นการให้เหตุผล (Reasoning) และการตอบคำถามในโดเมนเฉพาะทาง |
| **`Typhoon_fahmai_rag_challenge_1_original.ipynb`** | **Typhoon (SCB 10X)** | การประเมินโมเดล Typhoon บนกรอบการทำงาน Fahmai เพื่อวัดประสิทธิภาพความเข้าใจภาษาไทยระดับสูง |

* **องค์ประกอบร่วมของระบบ RAG:**
  1. **Document Ingestion & Chunking:** การแบ่งท่อนเอกสารภาษาไทยด้วยกลยุทธ์ที่รักษาระดับความหมาย (Recursive / Sentence Splitting)
  2. **Embedding & Vector Storage:** การสร้าง Dense Representations และจัดเก็บใน Vector Database (เช่น FAISS หรือ Chroma)
  3. **Context Retrieval:** การค้นคืนข้อมูลด้วย Semantic Search และ Cosine Similarity
  4. **Prompt Orchestration:** การจัดฟอร์แมต Prompt เพื่อให้โมเดลตอบตามบริบทจริง ลดการเกิด Hallucination
